# 🏆 AI 제품 디자인 스타일 분류 및 스크랩 마스터

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://pinterest-mgrg4evivaw4czvz9lu7qy.streamlit.app/)

핀터레스트에서 제품 디자인 레퍼런스를 자동으로 수집하고, OpenAI의 CLIP 모델을 사용하여 디자인 스타일별로 자동 분류해주는 AI 도구입니다.

## 🛠️ 주요 기능
1. **자동 스크래핑**: 키워드 입력만으로 핀터레스트의 고화질 이미지를 수집합니다.
2. **AI 디자인 분석**: CLIP(Deep Learning) 모델이 이미지의 조형적 특징을 분석합니다.
3. **스타일 분류**: 사용자가 정의한 디자인 언어(예: Braun, Minimalist 등)에 따라 이미지를 자동으로 그룹화합니다.
4. **원본 확대**: 수집된 이미지는 고해상도로 저정되며 클릭 시 원본 보기가 가능합니다.
